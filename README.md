# Traject Club Helper

Диагностический лаунчер для компьютеров клуба [Traject](https://traject.ru): сеть, пинг, звук, система, калибровка монитора и обход блокировок Discord и YouTube.

## Скачать

Готовые сборки лежат в [релизах](https://github.com/T-R-A-J-E-C-T/Club-Helper/releases/latest).

- **portable** — один exe, установка не нужна.
- **setup** — установщик Windows.

## Что внутри

- **Обзор.** Кнопка на главной ставит обход, если его ещё нет, и сразу включает.
- **Сеть.** Адрес, шлюз, DNS и проверка скорости.
- **Пинг.** DNS, лаунчеры и игры.
- **Звук.** Микрофон и наушники.
- **Система.** Сведения о компьютере.
- **Экран.** Калибровка монитора: максимальная частота, которую видит Windows, режим FPS, яркость и контраст 100.
- **Обход.** Zapret от Flowseal. Можно поставить не только последнюю версию, но и любую из списка.
- **Настройки.** Автозагрузка, запуск в трее и открытие Discord после включения обхода с главной.

## Сборка

Нужны Node.js 22 и Windows.

```bash
npm ci
npm run dev
npm run build:win
```

`npm run build:win` собирает установщик и портативную версию в `dist/`.
